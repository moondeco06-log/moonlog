# リール背景動画の置き場（自動ローテーション）

ここに **.mp4 を置くだけ** で、毎朝のリールが日付で自動的に背景を切り替えます。

## 夏紀さんへ：Canvaで作る背景の条件
- サイズ：**1080 × 1920**（縦・9:16）
- 長さ：**数秒でOK**（自動でシームレスループ＝ブーメランにします）
- 世界観：**夜空・銀河・月・星**（「月のメッセージ」シリーズの統一感）
- 動き：ゆっくりがいい（激しい動きは文字が読みにくい）
- ファイル名：何でもOK（例 `bg_01.mp4` 〜 `bg_07.mp4`）

## 仕組み
- 7枚置けば「7日ごとに一巡」して、プロフィールのグリッドに変化が出る
- 日付で自動選択（`日付の通し番号 % 枚数`）→ 毎日違う絵になる
- まだ0枚／不足でも `reels/リール元画像canva.mp4` に自動フォールバックするので投稿は止まらない

## 完成したら
枚数が増えるほど見栄えがよくなります。1枚ずつ追加でもOK（追加した瞬間からローテに加わる）。
